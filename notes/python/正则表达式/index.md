# 正则表达式

## `group()`分组：

正则表达式用括号来进行所索取内容的分组，可以对所得的正则匹配内容使用group()方法取出对应的某一组，其中group的使用方法有：

group(0)代表不取某一组，进行完整匹配

group(1)代表取第一个括号内容，即第一组，剩下的以此类推

### 四、贪婪 vs 非贪婪

```plain text
文本: "<div>hello</div>"
<.*>    → 匹配整个 "<div>hello</div>"  (贪婪，一口吃到底)
<.*?>   → 匹配 "<div>"               (非贪婪，遇到第一个 > 就停)
```
